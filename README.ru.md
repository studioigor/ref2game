## Установка одним промптом

Отправьте этот промпт вашему агенту (Claude Code или Codex):

```text
Установи скилл ref2game https://github.com/studioigor/ref2game
```

В репозитории две редакции одного скилла. Claude Code берёт папку `claude/`, Codex — папку `codex/`. Дальше отправьте `/ref2game` в Claude Code или `$ref2game` в Codex и приложите референс.

---

**ref2game** превращает референс в готовый прототип игры, в который можно поиграть в браузере. Картинки генерируются по кусочку, в стиле референса. Всё, что двигается, — это код в крошечном движке на WebGL2: риги, циклы ходьбы, ветер, свет, частицы, камера, интерфейс и ощущение от управления. Страница меняется у вас на глазах, пока агент работает.

**ИИ рисует. Код оживляет.**

## Две редакции

| | `claude/` для Claude Code | `codex/` для Codex |
|---|---|---|
| Генерация картинок | на выбор: встроенный image_gen из Codex, любой API картинок (агент сам изучит документацию и подключит, бюджет задаёте вы), локальный инструмент или картинки вручную | встроенный imagegen сессии |
| Вопросы | варианты ответа, рекомендованный первым | через инструмент ввода Codex или коротко в чате |
| Критики | фоновые сабагенты, оценки приходят следующим сообщением | сабагенты, результаты учитываются до конца хода |

Движок, риги, проверки и справочники в обеих редакциях одинаковые.

## Как это выглядит

```text
Вы       /ref2game  [скриншот шутера с видом сверху]
Агент    Один раунд вопросов: каким генератором рисовать, что делает игрок, какой объём.
Агент    Живая страница готова: уровень уже бегает на заглушках.
Агент    Арт приезжает по кусочку: фон, земля, пропсы, герой, толпа.
Агент    Ворота A: референс рядом с нашим кадром, расхождения в цифрах.
Агент    Риги, ветер, свет, сочность. «Попробуй WASD + мышь, рывок на Space, взорви баллон».
Вы       Зомби скользят, ноги едут по земле.
Агент    Стопы поставлены на пути, колени через IK. Проверка скольжения теперь гоняется на каждой правке.
```

## Чем он отличается

- 🎨 **ИИ рисует, код управляет.** Одна генерация — один кусок, всегда с референсом и библией
  стиля. Свечение, тени, частицы, текст и вода никогда не запекаются в картинку: ими владеет
  движок, поэтому ничего не застывает и не двоится.
- 🦴 **Настоящие риги, а не качающиеся спрайты.** Каждый актёр, от игрока до лошади у костра,
  получает риг из вырезанных частей: двухкостные конечности, круглые суставы, ближняя и дальняя
  сторона. Нарисованное одним куском животное гнётся «мягкими костями» в шейдере. Сдвиг или
  поворот всего спрайта анимацией не считается.
- 📏 **Движение измеряется.** Каждый риг сообщает координаты суставов. QA-скрипт проверяет
  скольжение стоп, хромоту, ширину шага, сгиб колен, растяжение, фазу рук, рывки между
  состояниями и то, попадает ли клинок в цель в кадре удара — для целей со всех сторон.
- 🌬️ **Живое — это системы.** Один ветер с бегущими порывами гнёт траву, деревья, плащи и
  фонари. Мир отвечает игроку, у каждого события своя многослойная сочность.
- 🔍 **Независимые критики.** Критики ассетов, модулей, движения, кадра, похожести и геймплея
  работают в фоне. Критик похожести сравнивает кадр с референсом в цифрах: раскладка, яркость,
  палитра, световые пятна, размеры персонажей.
- ⚡ **Прогресс виден через минуты.** Страница перезагружается через секунду после каждой правки
  и сохраняет состояние игры. Генерация идёт параллельно, пока пишутся эффекты.
- 🧷 **Каждый дефект становится проверкой.** Всё, что вы нашли, чинится, а потом новая
  автоматическая проверка не даёт вернуться всему классу таких дефектов.
- 🕹️ **Любой 2D-жанр, любой стиль.** Платформер, вид сверху, изометрия, шмап, головоломка,
  карточные игры; пиксель-арт, живопись, cel и чернила, плоский вектор, акварель, неон.

## Попробуйте сказать

- *«Сделай игру как здесь»* и приложите скриншот
- *«Оживи этот концепт-арт как платформер»*
- *«Сделай играбельный кусок в стиле этого видео»*
- *«У него ноги скользят при ходьбе»* — внутри идущего проекта
- *«Упакуй»* — статичная сборка и ассет-пак

## Что нужно

Claude Code или Codex, Python 3.9+ с Pillow, NumPy и SciPy, Node.js 18+, macOS или Linux.
Playwright с Chromium ставится внутрь скилла при первом запуске. ffmpeg нужен только для
видео-референсов и рендера видео.
